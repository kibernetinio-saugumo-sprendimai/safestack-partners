# Support

This repository is a curated directory and documentation project. It is not a support channel for the third-party products and services listed here.

For a catalogue correction or broken link:

1. open an issue using the appropriate template;
2. provide the exact page, the observed problem and a proposed correction;
3. avoid including credentials, private keys or confidential data.

For security-sensitive reports, follow [SECURITY.md](SECURITY.md) instead of opening a public issue.

For questions about a listed external service, use that service's official support or security channel.
